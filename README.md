# جارفس - المساعد الذكي الشخصي

جارفس هو مساعد ذكي شخصي للجوال يعمل بنظامي Android و iOS.
واجهة سينمائية بتصميم مستقبلي (مستوحاة من Iron Man).

## المميزات
- 🎙️ محادثة صوتية بالعربية
- 🔊 ردود صوتية بالعربية
- 🗺️ فتح الخرائط والبحث عن أماكن
- 🌌 واجهة مستقبلية مع نواة متحركة

## الحالة الحالية
الإصدار الأول - الأساسي (بدون ذكاء اصطناعي متصل)
